# Windows 11 performance snapshot

Recorded 2026-09-23 from the optimized x64 release on Windows 11 build
10.0.26100, at 120 DPI (125% display scaling). The benchmark uses an isolated
temporary profile and a placeholder key; it sends no microphone audio and
makes no Gemini request.

## Package and window size

| Measurement | Result |
| --- | ---: |
| Release executable | 1,533,952 bytes (1.46 MiB) |
| Windows icon | 370,070 bytes (0.35 MiB) |
| Portable release ZIP (EXE + icon) | 992,583 bytes (0.95 MiB) |
| Pill | 252 × 48 logical px (315 × 60 physical px at 120 DPI) |
| Settings window | 414 × 500 physical px |

Utterly ships as a portable ZIP, not an installer. The uncompressed EXE and
icon together occupy 1.82 MiB, below the 5 MB size allowance.

## CPU and memory

CPU is process CPU time divided by elapsed wall time, expressed as a percent
of one logical core. Memory figures are the peak sampled every 200 ms during
each interval. Private bytes are app-owned committed memory; working set also
includes shared Windows and DLL pages.

| State | Sample | CPU, one core | Peak private | Peak working set |
| --- | ---: | ---: | ---: | ---: |
| Idle | 30.21 s | 0.21% | 4.60 MiB | 22.39 MiB |
| Settings open | 5.02 s | 0.62% | 4.89 MiB | 25.10 MiB |
| Pill drag | 6.01 s | 2.86% | — | — |
| Settings caption drag | 6.02 s | 2.08% | — | — |

The idle process stays under 5 MiB private memory. Windows working set is
higher because it includes shared system pages; the highest observed value
while the settings window was open was 25.10 MiB. No sustained CPU work runs
in either drag path: the pill delegates movement to the OS, and the settings
window uses the standard Windows caption drag.

## Drag sample

The benchmark moved each window over six seconds using a 30 Hz pointer path.
The pill moved 72 × 37 physical pixels for a requested 72 × 36 path (the
one-pixel difference is Windows positioning/rounding); the settings window
moved exactly 72 × 36. Both stayed responsive, and process CPU stayed below
3% of one core during the measured motion.

## Reproduce

From the repository root, after a release build:

```powershell
cargo build --release
.\scripts\benchmark-windows.ps1 -IdleSeconds 30 -DragSeconds 6
```

The script prints the executable and ZIP sizes, OS/DPI, window dimensions,
idle and settings-open CPU/memory, caption/pill drag CPU and displacement, and
whether closing Settings hides it. It writes only a disposable profile and
package staging files under `%TEMP%`.
